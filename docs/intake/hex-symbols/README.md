# Supplied hex-symbol pack — intake material for IN-089

**This directory is inert.** Nothing here is referenced by `HEX_TERRAIN_CATALOG`,
`HEX_CONTENTS_CATALOG`, the build, or any test. It is the 37 `.svg` files the user
supplied with the 2026-09-02 hex-tools batch, parked so the intake item has its
material when it is eventually scheduled.

The wired-up art lives at `apps/web/public/assets/hex/terrain/*.svg` and
`apps/web/public/assets/hex/contents/*.svg`. Moving a file from here to there is
part of the work item that lands IN-089, never a side change (RULE-015).

## What the pack is

37 files, uniform shape: `viewBox="0 0 100 100"`, `fill="none"` on the root,
`stroke-linecap`/`stroke-linejoin` round, a `<title>`, and an `aria-label`. Every
drawn element carries `class="ink"`. Schematic hex-crawl cartography — a castle is a
square, a town is a filled circle — not pictorial illustration.

Three facts about the pack decide how it can be wired up, and are why IN-089 is
classified Deceptive. The first two still stand; the third is now answered:

1. **The ink is `#111111`, not white.** `packages/shared/src/map/hex/catalog.ts`
   states the opposite requirement in as many words: "The art is authored white,
   unlike the black dungeon-symbol pack: both overlays are tinted at the render
   boundary … and a tint multiplies, so black art could not be tinted lighter."
   A `#111111` glyph tinted toward a light `HEX_OVERLAY_LIGHT` stays `#111111`.
2. **`sym-water.svg` is two-tone** — `class="tint ink"`, `fill="#a8c4d0"` with a
   `#111111` stroke. A single multiply tint has no way to express two tones.
3. **No licence or authorship metadata in the files.** SPEC-003 §5's licence
   discipline is a permanent standing constraint and cites an `ATTRIBUTION.md` that
   does not yet exist (IN-078).

   **Provenance is on record (user, 2026-09-02): there is no third-party source.**
   The project owner states these were generated by Claude in a separate session, for
   a separate project of their own, and supplied here — nothing cloned, traced or
   copied from a licensed pack. WI-101 creates `ATTRIBUTION.md` and records that, as
   the owner's own generated art rather than third-party work, before any file moves
   into `apps/web/public/`.
