## WI-076 — Edit/View as one binary button; default View on session join

**Changes made.**

- `apps/web/src/lib/shell/map-tool-controller.svelte.ts` — `mapMode`'s initial `$state`
  value changed from `'edit'` to `'view'`; doc comment cites DEC-064. `setMapMode`/
  `MapToolMode` otherwise untouched.
- `apps/web/src/lib/components/MapToolbar.svelte` — the two-button `map-mode-edit` /
  `map-mode-view` pair replaced by one `<button data-testid="map-mode-toggle">` whose
  label tracks `mapMode`, `aria-pressed={mapMode === 'edit'}`, toggling on click.
- `apps/web/src/lib/shell/map-tool-controller.test.ts` — the "defaults to edit, unlocked"
  case now asserts `'view'` (DEC-064).
- `apps/web/tests/e2e/helpers.ts` — new `switchToEditMode(page)`.
- `apps/web/tests/e2e/{battle-map-capture,battle-map-lifecycle,fog,map-draw-feedback,
  mobile,presentation,rooms-manager}.spec.ts` — each file's `createRoomAndJoin`/
  `createRoomAsGm` now calls `switchToEditMode` after joining, so map-drawing specs keep
  behaving as under the old Edit default. `fog.spec.ts`'s referee-only test also switches
  the player page to Edit (the lock is per-viewer). `map-draw-feedback.spec.ts` targets the
  single `map-mode-toggle` testid in place of the retired pair (RULE-005).
- `README.md` — the Edit/View soft-lock paragraph documents the single toggle button and
  the `'view'` default, citing DEC-064.
- `PLAN.md`, `INTAKE.md`, `PLAN-COMPLETED.md` — ledger moves.

**Visible behavior changes.** The Map tools sheet shows one `Edit`/`View`
button instead of two; clicking it toggles between the two states. Every
freshly joined session (referee or player) now starts with the map in View —
the carve/edit tools are locked until that button is clicked to enter Edit.
Previously every session started in Edit, unlocked.

**How to verify.** Join a room in a fresh tab → open the Map tools sheet →
the carve/edit tools (Room, Wall, Door, etc.) are disabled and the button
reads `View`; click it → the button reads `Edit` and the tools are enabled.
Automated: `pnpm verify:all` (lint, typecheck, and the full emulator suite —
unit, rules, store, e2e) — all green, `all suites green` (722s for the
emulator suites).

**Deviations.** None beyond what DEC-064 called out as in-scope: the e2e updates for the
new View default and merged testid are exactly the work the decision named.
