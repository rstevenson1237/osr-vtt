**Visible behavior changes** — tabbing to any icon-only shell control (the quick-sheet
rail, the view tabs, the activity drawer's trigger, the mobile top bar's gear, the
fullscreen toggle, the session tab's gear, every map-tool button, and the Log button) now
draws a visible 2px ring in `--focus` (`#6fa8dc` on `parchment-dark`, `#2f6fb0` on
`keyed-blue`), offset 2px outside the button's border. Clicking or tapping the same
controls with a pointer draws no ring (`:focus-visible`, not `:focus`). Nothing else about
these controls — position, size, colour at rest, disabled styling — changes.
