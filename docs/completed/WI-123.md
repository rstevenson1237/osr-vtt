# WI-123 — Retire the two superseded pre-pack contents glyphs

**Spec:** SPEC-047 §10 · **From:** IN-116 · **Agent:** `claude-code` · **Model:** `sonnet` ·
**Effort:** S · **Closed:** 2026-09-11

## Changes made

- `packages/shared/src/map/hex/catalog.ts` — `HexContentsEntry` gains an optional
  `paintable?: boolean` field (default true, mirroring WI-121). The `tower` row's `ref`
  moves to `tower-keep`'s art and the `ruins` row's `ref` moves to `ruin`'s art; both now
  carry `paintable: false`. Neither row's `kind`/`label` changed, so no migration is owed
  (RULE-007). `danger` is untouched — kept pickable on its WI-040 art per DEC-091 (c).
  Added `paintableHexContentsCatalog()`, mirroring `paintableHexTerrainCatalog()`.
- `apps/web/src/lib/components/shell/HexTilePanel.svelte` — the contents palette
  (`CONTENTS`) now comes from `hexMap.paintableHexContentsCatalog()` instead of a
  component-local `unknown`-only filter over `HEX_CONTENTS_CATALOG`.
- `apps/web/src/lib/components/MapToolbar.svelte` — the hex Symbol tool's kind picker
  (`HEX_SYMBOL_KINDS`) now maps `hexMap.paintableHexContentsCatalog()` instead of the raw
  `HEX_CONTENTS_CATALOG` (which previously offered `unknown` too, by omission).
- `packages/shared/src/map/hex/catalog.test.ts` — new test: `ruins`/`tower` resolve to
  `ruin`/`tower-keep`'s art and are excluded from `paintableHexContentsCatalog()`; `danger`
  keeps its art and palette slot.

## Visible behavior changes

- The hex-tile quick sheet's contents row and the Symbol tool's kind picker no longer offer
  `Ruins` or `Tower` (nor `Unknown`). A hex already carrying either kind still renders — now
  drawing `ruin`'s/`tower-keep`'s art, since only `ref` moved, not `kind`. `Danger` is
  unaffected.

## How to verify

- `pnpm verify` (lint + typecheck + unit) — green.
- Manually: open a hex map, select a hex; the contents swatches and Symbol toolbar picker
  no longer list `Ruins`, `Tower` or `Unknown`; `Danger` still appears. A hex stored with
  `ruins`/`tower` now draws the pack's `ruin`/`tower-keep` glyph.
