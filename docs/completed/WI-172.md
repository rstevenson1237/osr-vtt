# WI-172 — Measured reads/writes/listeners per session

**Closed 2026-09-23.** From IN-179. **Investigation — a number in `README.md`, no
production code changes** (RULE-015). Model target `sonnet`, run on `sonnet`; effort
medium.

## Method

Ran `apps/web/tests/e2e/two-context.spec.ts` (the Phase 0 vertical slice: GM creates and
joins a room, a player joins, the GM adds and drags a token, the player edits a profile
field and rolls it, both open the log, the player reloads) against the real Firebase
Emulator Suite. `packages/shared/src/store/firebase-store.ts`'s imports of the
Firestore/RTDB SDK functions (`getDoc`, `getDocs`, `setDoc`, `updateDoc`, `deleteDoc`,
`writeBatch`, `onSnapshot`, and the RTDB `get`, `set`, `remove`, `runTransaction`,
`onValue`) were temporarily wrapped with counters exposed on `globalThis.__opCounts`,
split by backend and operation kind (`getDocs` counted by `snapshot.size`, matching
Firestore's per-document read billing; a `writeBatch`'s `.set`/`.update`/`.delete` each
counted individually, matching per-op billing within a batch). The spec read the counter
off each browser context at the end of the run. Both the instrumentation and the
temporary read-out line in the spec were reverted (`git checkout --`) before this record
was written — the only change this item ships is the README paragraph.

## Result

For the room as a whole (GM seat + player seat, one open-to-close session):

| Measure | GM | Player | Total |
| ------- | -: | -: | -: |
| Firestore reads | 5 | 0 | 5 |
| Firestore writes | 10 | 1 | 11 |
| Firestore listeners (`onSnapshot`) | 23 | 26 | 49 |
| RTDB reads (`get`) | 0 | 0 | 0 |
| RTDB writes | 27 | 3 | 30 |
| RTDB listeners (`onValue`) | 5 | 5 | 10 |

Firestore writes are comfortably inside RULE-003's 20k/day budget even at dozens of such
sessions a day. RTDB write volume (presence heartbeats, cursor/drag-frame updates) is not
billed per-write on Spark and is what RTDB is for (RULE-003). The listener count is
per-seat rather than per-room, so it is the number that scales with players in a room.
