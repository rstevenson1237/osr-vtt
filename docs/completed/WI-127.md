## WI-127 — Letter control repositioning in quick sheet

**Status: Completed 2026-09-14**

The quick sheet's Letter control moves below the colour swatches at docked width.

### Changes made

- **CharacterDock.svelte**, `<style>` block: Added `flex-wrap: wrap` to `.token-color` container, and new rule for `[data-testid="token-letter-control"]` with `flex-basis: 100%` and `margin-top: 0.4rem` to reposition the Letter control below the swatches.

### Visible behavior changes

None beyond layout: the Letter control now appears on its own line below the colour swatches instead of being pushed off the sheet at docked width. No DOM structure changes, no testid changes.

### How to verify

1. `pnpm verify` — lint, typecheck, unit tests all pass.
2. Open a character sheet on a docked-width viewport and observe the Letter control appearing below the colour swatches instead of off-screen.

### Deviations

None.
