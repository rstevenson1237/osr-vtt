## Changes made

- `apps/web/src/lib/components/shell/Icon.svelte` — six existing `MARKUP` entries redrawn
  (`encounter`, `session`, `room`, `corridor`, `ngon`, `polygon`) per SPEC-051 §6, using the
  exact geometry (including the two computed paths, `session`'s gear and the later `rotate`
  glyph's arc) from `docs/mockups/icon-audit-2026-09-18.html`'s `NEW`/`gear()`/`rotateCw()`.
  41 new entries added per SPEC-051 §5: four hex-only tools (`road`, `river`, `terrain`,
  `hex`), 25 chrome verbs (`close` … `minus`), and 12 text-only actions (`link` … `note`).
  The `size` prop changed from a numeric default (`20`) to `number | 'sm'`: unset resolves to
  `var(--icon)`, `'sm'` to `var(--icon-sm)`, and a literal number still renders at that fixed
  pixel size. Sizing moved from the `width`/`height` attributes to an inline `style`, since a
  CSS custom property can't be assigned to an SVG presentation attribute directly.
- `apps/web/src/lib/shell/types.ts` — `IconId` grows from 34 to 75 entries (the 41 new ids
  above); the six redrawn ids are unchanged as identifiers.
- `apps/web/src/lib/theme/sizing.css` — two new tokens, `--icon` (20px precise / 24px coarse)
  and `--icon-sm` (16px precise / 20px coarse), alongside the existing `--hit`/`--hit-inline`,
  picked by the same `(pointer: coarse)` query. The file's scope note is split: `--hit`/
  `--hit-inline` stay frame-chrome-only, `--icon`/`--icon-sm` are declared unscoped since a
  glyph's size follows pointer coarseness wherever it renders (map palette included).
- The 13 existing `<Icon>`/`<PresentationToggle>` call sites (`MapToolbar.svelte` ×4,
  `RoomShell.svelte`, `MobileTopBar.svelte` ×2, `SessionTab.svelte` ×2,
  `ActivityDrawer.svelte`, `QuickSheetRail.svelte`, `MainViewTabs.svelte`,
  `ActionLog.svelte`) — their six ad-hoc numeric sizes (14, 15, 16, 18, 19, and the unused
  default 20) replaced with the two tokens per SPEC-051 §2's mapping: a dense-row/inline
  control (map-toolbar group icons, the session gear, both bars' Log/tab variants at their
  compact size, log rows) takes `size="sm"`; a standalone control (map palette tool buttons,
  the activity drawer, the rail/desktop variants of the quick-sheet rail and main-view tabs)
  takes no `size` prop at all, falling to the new default. `PresentationToggle.svelte`'s own
  `size` prop and default changed the same way (`number | 'sm'`, default `'sm'`).
- `README.md`'s "Icon system" section — retitled to cite SPEC-051 alongside SPEC-043, and
  extended with the record's new size (75 entries, the six redraws, the 41 new ids, the
  mirror-pair convention) and the three render stops.

## Visible behavior changes

Six existing icons render differently (the redraws in SPEC-051 §6): `encounter` is now
crossed swords, `session` a toothed cog, `room` a plan-view floor plan, `corridor` a closed
L-shaped run, `ngon` a pentagon with a centre dot, `polygon` an irregular hexagon. The 13
existing icon call sites render at very slightly different pixel sizes on some devices, per
SPEC-051 §2's stop table (e.g. the mobile top bar's session gear moves from 14px to 20px on a
coarse pointer). The 41 new ids are not yet drawn anywhere — no panel, button or toolbar
consumes them until WI-140/141.

## How to verify

`pnpm verify` (lint + typecheck + unit) — green. Visually: open the app on desktop and on a
narrow/touch viewport and confirm the six redrawn icons (main-view tab / activity drawer /
map-tool-palette Encounter, Room and the palette's Corridor, N-gon and Polygon tools) and that
nothing looks unstyled or missing at either pointer coarseness.

## Deviations

None — the six-redraw geometry, the 41 new `MARKUP` entries and the two computed paths
(`session`'s gear, `rotate`'s arc) are copied verbatim from the audit mockup's `NEW`/`gear()`/
`rotateCw()` output, which is the reference this work item cites. The 13 call sites' ad-hoc
sizes are migrated to the two tokens in this same change (SPEC-051 §2's own stated end state
for them), rather than left for a later item, since the tokens introduced here would
otherwise remain unconsumed by any existing caller.
