# WI-199 — Playwright fail-fast

**Batch 4** (with WI-200). Closed 2026-09-23.

## Changes made

- `apps/web/playwright.config.ts`: Added `maxFailures: 1` to stop on the first failing test, and `globalTimeout: 2 * 60 * 60 * 1000` (2 hours) to bound the entire test suite and prevent individual test timeouts from cascading.

## Visible behavior changes

When running e2e tests with a systemic failure (e.g., emulator down, WebGL unavailable), the test suite now exits on the first failure instead of serially timing out every remaining test, reducing total test runtime and clarifying the root cause.

## How to verify

- Run `pnpm test:e2e` or `pnpm verify:all` against a working emulator — suite completes normally (no change to successful runs).
- To observe fail-fast behavior, shut down the Firebase emulator and re-run `pnpm test:e2e` — it now exits after the first test timeout instead of attempting all tests.
