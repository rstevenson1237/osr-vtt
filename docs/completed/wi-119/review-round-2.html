2. Naming: lean on the traditional names, not the old scheme

Your read: don't retrofit the richer Worldographer roster onto the old, smaller vocabulary — lean on the traditional names themselves, since they'll make more sense to a new user than a mapping back onto categories this app invented. Concretely, that most likely means: for authoring new hexes, the palette should offer the new named kinds (Jungle, Hills, …) and not also offer the old kind under a second name that now draws identical art — the two rows below are visually the same shape, so a picker with both is confusing rather than backward-compatible. Old stored values (a hex already painted "Palm") still resolve — RULE-007 requires that regardless — this is only about what a referee is offered when painting a *new* hex. Flagging for confirmation before WI-120 builds the picker either way.
