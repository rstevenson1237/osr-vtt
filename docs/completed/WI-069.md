### Deviations

- **The approved plan said `CLAUDE.md` ≤ 100 lines; it is 136.** Cutting further meant
  dropping the Deceptive trigger list, which is load-bearing for triage.
- **`docs/spec/SPEC-035.md` was created.** `PLAN.md` cited SPEC-035 for this work item but
  no such spec existed. Writing it is required by RULE-018 (a PR implementing a spec that
  does not move that spec's status is incomplete), so it is taken under the RULE-015
  unblocking exception rather than deferred.
- **`PLAN-COMPLETED.md` did not get the per-item bullet index** the split script initially
  produced — the existing §3 table already carries every item with more metadata, and the
  path is derivable from the id, so the bullet list was pure duplication.
- **`pnpm test:unit` fails in this environment** (`account-recovery.emulator.test.ts`,
  `signInAnonymously`), because no Firebase emulator is running. Confirmed pre-existing by
  stashing the change and re-running against the base commit; unrelated to this work item
  and not fixed here (RULE-015).
- **Not done, deliberately:** the audit's tables-to-bullets conversion of `INTAKE.md` and
  `PLAN.md` (a few percent of two on-demand files, against a real loss of scannability),
  and its `chmod -x` of the archive guard (see DEC-056).
