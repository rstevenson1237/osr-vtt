# WI-164 — Path measurement; drag-distance chip

SPEC-054 §12. Part of Batch 2b (WI-159, WI-161, WI-164, WI-165) — one pull request, one
combined summary.

**Changes made**

- `apps/web/src/lib/map/vector-tools.ts` — two new exports: `pathMeasureText` (sums each
  leg's Euclidean length across a multi-point path, formatted through the same
  `formatSpan` `measureSpanText` uses) and `hexPathMeasureText` (the hex-map counterpart,
  summing `hexMap.axialDistance` per leg — RULE-006, a hex map's only distance).
- `apps/web/src/lib/map/vector-engine.ts` — `ToolPreviewInput.ruler` widens from a single
  `{a, b}` span to `readonly Point[] | null`, drawn as a connected polyline (one segment
  per leg) with end-cap ticks at only its first and last point, in place of the old
  two-point line.
- `apps/web/src/lib/components/VectorMapView.svelte` — the Measure tool changes from
  click-and-drag (one span, cleared on pointer-up) to click-to-extend: `measureDrag`/
  `measureHexDrag` become `measurePath`/`measureHexPath` (accumulated arrays) plus
  `measureLive`/`measureHexLive` (the pointer's live extension of the last leg, mirroring
  the wall/polygon multi-click pattern). Each click appends a point
  (`handleCollabPointerDown`); pointer-move only updates the live point; pointer-up is a
  no-op. A new `finishMeasure()` ends the path on double-click, mirroring `cancelStroke`'s
  existing handling of Escape (both already clear the renamed path state, no write either
  way). The readout and ruler line are computed from `pathMeasureText`/
  `hexPathMeasureText` over the path plus its live extension.
  - The token-drag distance chip: `attachDragHandlers` now captures the drag's start point
    in lattice units and, on each `globalpointermove`, computes the distance to the
    current position via `measureSpanText` (unchanged — a straight two-point span) and
    shows it in a small `PIXI.Text` positioned beside the token, owned directly by the
    drag handler (destroyed on drop) rather than routed through the full-map
    `renderToolPreview` pass that a continuous per-pixel-move call would have made
    noticeably heavier.
- `apps/web/src/lib/map/vector-tools.test.ts` — new tests for `pathMeasureText` (sums legs
  rather than the endpoint span; matches `measureSpanText` on a single leg; null for a
  degenerate/short path) and `hexPathMeasureText` (sums per-leg `axialDistance`; null
  cases).

**Visible behavior changes** — the Measure tool now accepts further clicks after the
first: each extends the path, the readout and ruler line track the running total, and
Escape or a double-click ends it (previously: a single click-and-drag span, cleared on
release). Dragging a token now shows a small chip beside it with the distance travelled
from where the drag began, in the map's units.

**How to verify** — `pnpm verify` green. Manually: pick Measure, click several points
across the map — the ruler extends and the readout keeps a running total; press Escape (or
double-click) to end it. Drag any token and watch the distance chip track the drag,
disappearing on drop.

**Deviations** — none.
