# WI-177 — Handouts quick sheet

SPEC-056 §1. Single unit (Deceptive). IN-158.

**Changes made**

- `apps/web/src/lib/shell/types.ts` — `QuickSheetId` gains `'handouts'`.
- `apps/web/src/lib/shell/activities.ts` — `QUICK_SHEETS` gains a `handouts` entry, added
  last in the referee group (`availability: 'gm'`, icon `note`), so every existing digit
  shortcut keeps its key. Doc comment updated to list handouts among the referee-only
  exceptions.
- `apps/web/src/lib/components/shell/sheets/HandoutsSheet.svelte` (new) — a thin wrapper
  around the existing `HandoutPanel`, following the `TablesSheet`/`BattleSheet` pattern.
- `apps/web/src/lib/components/RoomShell.svelte` — imports `HandoutsSheet` and adds the
  `handouts` case to the `sheetBody` snippet, passing `room.handout?.ref ?? null` the same
  way `SessionActivity` used to.
- `apps/web/src/lib/components/shell/SessionActivity.svelte` — the Handout section and its
  now-unused `HandoutPanel` import removed; the file's header comment updated to point at
  the new sheet.
- `apps/web/tests/e2e/helpers.ts` — `QuickSheetName` gains `'handouts'`.
- `apps/web/tests/e2e/portability.spec.ts` — `revealHandout()` opens the Handouts quick
  sheet (`expandQuickSheet(gm, 'handouts')`) instead of the Session activity; the
  export/import round-trip test, which used to rely on `revealHandout` leaving Session
  open, now opens Session settings itself before clicking `session-export-room`.
- `README.md` — the quick-sheets table (§"Session shell — quick sheets") gains the
  `handouts` row.

`HandoutPanel.svelte` itself is unchanged, so every testid it owns (`handout-panel`,
`handout-title`, `handout-ref`, `handout-save`, `handout-hide`, `handout-row-*`,
`handout-reveal-*`, `handout-delete-*`) moved with it (RULE-005). The player-side
`HandoutViewer`/`handout-viewer` is untouched.

**Visible behavior changes** — the referee's handout library and reveal/hide controls now
live in their own quick sheet (rail icon, docked/expanded/mobile like any other sheet)
instead of a section of the Session settings modal. Players never saw it either way.

**How to verify** — `pnpm verify:all` green (lint, typecheck, unit, rules/store contract
suites, and the full Playwright e2e suite against the emulators, including
`portability.spec.ts`'s handout-reveal and export/import round-trip tests). Manually: sign
in as referee, open the Handouts quick sheet from the rail (referee group, after Random
tables), save and reveal a handout — Session settings no longer shows a Handout section.

**Deviations** — none. (One follow-on fix, `apps/web/tests/e2e/portability.spec.ts`'s
export/import test needing an explicit `openActivity(gm, 'session')` before the export
click, is the unblock exception: `revealHandout` no longer leaves Session settings open,
so the later `session-export-room` click had nothing to act on without it.)
