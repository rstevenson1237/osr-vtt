# WI-231 — Stage pointer dispatch leaves `wireStagePointerEvents` for `MapPointerRouter`

**Closed 2026-10-22.** From IN-204. SPEC-069, SPEC-060 §4, DEC-136 (a). Model target
`sonnet`, run on `sonnet`; effort `high`.

---

## Changes made

- `apps/web/src/lib/map/map-pointer-router.ts` (new): `MapPointerRouter`. `new
  MapPointerRouter(handlers, { gestureActive })` drops null entries; `attach(host)` wires the
  stage's `pointerdown`, `pointermove`, `pointerup`, `pointerupoutside` and `pointerout`,
  converts each event once with `toWorld`, and `detach()`/`destroy()` remove them. Down returns
  early under the guards (gesture in progress, non-primary button, Alt) then first consumer
  wins; move runs every `hover` and then first consumer wins; up awaits each handler in turn;
  `pointerOut()` and `cancel()` fan out. `StageHost`/`StageEmitter` are the structural types a
  test fakes.
- `apps/web/src/lib/map/map-seam.ts`: `StageInput` (`hover`, `pointerDown`, `pointerMove`,
  `pointerUp`, `pointerOut`, `cancel`, all optional).
- `map-draw.svelte.ts`: `publishCursor` becomes `hover` (the throttled cursor publish).
  `map-hex.svelte.ts`: new `hover` (note hover + preview point); `pointerMove` keeps only the
  fog stroke. `map-labels.svelte.ts`: the tooltip hover is private `#hoverAt`, and a `stage`
  facet exposes `hover`, `pointerDown`, `pointerOut` and `cancel` (= `dismissTooltips`).
- `apps/web/src/lib/components/VectorMapView.svelte`: `wireStagePointerEvents` is gone. The
  router is built in `onMount` right after the hex controller, over `[labels.stage, hex, draw,
  editor]` with the ordering reasons on the list, attached when the engine exists, destroyed in
  `onDestroy`. `editor` is the new object literal holding the Label/Symbol/Text clicks, the
  `onPointerDown/Move/Up` tail with its two conversions and `syncMeasureReadout()`, the hex-map
  background drag, and the stroke-state reset. `cancelStroke` is `pointerRouter?.cancel()` plus
  `renderAll()` and `syncMeasureReadout()`. The `dblclick` listener moves to `wireDoubleClick`.
- Tests: `map-pointer-router.test.ts` (new, 14: guards; first consumer wins on down, move and
  up; every hover before any move even when the first handler consumes; up awaits each handler;
  null entries dropped; `pointerOut`/`cancel` reach every handler; `detach` removes every
  listener). `map-labels.test.ts` (facet: `cancel` dismisses tooltips and leaves an open editor
  alone), `map-draw.test.ts` and `map-hex.test.ts` follow the renames and the hover/move split.
- Docs (RULE-018): SPEC-069 → Active (list shows `labels.stage`; §5 records the background
  drag and the cancel list), `SPEC.md` index, SPEC-060 §4, SPEC-066 §5, `README.md` (the note
  dot and a "Stage pointer dispatch" paragraph under "Seam controllers"), `PLAN.md`,
  `PLAN-COMPLETED.md`, `INTAKE.md`.

## Visible behavior changes

None. Every store call, argument and undo entry is the one made before; no layer, layer order,
testid or coordinate meaning changed.

## Deviations

- **Two members of the dispatch that SPEC-069 §4 did not name.** (1) The `label` tool's click
  sat in the ladder after the hex branch; it is `editor`'s first down branch, in the same
  position relative to everything else. (2) The hex-map background drag was a move branch
  between `hex` and `draw`; it is `editor`'s first move branch. Not a reordering: it begins
  only from Select and a tool change cancels it (`cancelStroke`), so `draw` (Ping/Pen/Measure)
  never consumes a move while it is live. SPEC-069 §5 now says so. Unblock exception.
- **`labels` is entered as `labels.stage`**, not the `MapLabels` object: `MapLabels.cancel()` is
  the label editor's own cancel, and a router `cancel()` fan-out would have closed an open
  editor on a pan gesture. SPEC-069 §4 now says so. Unblock exception.
- **Down order is `hex` then `draw`** (the ladder had `draw` then `hex`), as SPEC-069 §4
  specified. Checked rather than assumed: `hex.pointerDown` consumes only on Select and the five
  hex tools, `draw.pointerDown` only on Ping, Pen and Measure, so no tool reaches both; no
  intake item needed.
- No RULE-015 Deviations-budget fix was made.
