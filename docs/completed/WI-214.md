# WI-214 — One name rule for an unnamed creature

SPEC-055 §4, DEC-122. IN-218. Model `sonnet`, effort high.

## Changes made

- `apps/web/src/lib/components/CharacterDock.svelte` — the creature header (`dock-name`)
  resolves through `actorPresentation` instead of `creatureDisplayName`.
- `apps/web/src/lib/components/EncounterBoard.svelte` — `cardName()` is now one
  `actorPresentation` call (the seat-name branch moved into the resolver, which already had it).
- `apps/web/src/lib/tokens/labels.ts` — `creatureLabel` and `creatureDisplayName` deleted;
  one doc comment on `creatureBatchNames` updated.
- `apps/web/src/lib/tokens/actor-presentation.ts` — header comment updated (the
  disagreement is settled, not deferred).
- `apps/web/src/lib/tokens/labels.test.ts` — the `creatureDisplayName` tests removed with it.
- `apps/web/src/lib/tokens/actor-presentation.test.ts` — new block pinning DEC-122's rule:
  letter beats art, art-only reads `basename · id6`, same-art creatures differ, whitespace
  name/letter count as absent, no name/letter/art reads `Token <id6>`.
- `apps/web/tests/e2e/group-ownership.spec.ts` — the unnamed bundled-art creature's
  `dock-name` now expects `goblin.svg · <id6>` instead of `goblin`.
- `README.md` — "Creature names and symbols" and the quick-sheet header paragraph describe
  the single rule.
- `PLAN.md`, `PLAN-COMPLETED.md`, `INTAKE.md` — ledger close-out; IN-218 closed, IN-225 logged.

## Visible behavior changes

For an **unnamed** creature only: the Character quick sheet's header and the Encounter
Board card name now read the stored letter if there is one, else `<art filename> · <first six
characters of id>` (previously the bare filename without extension, or `Token <id6>`). A
named creature, a seat-owned token and the initiative order are unchanged. No schema, store
or `data-testid` change.

callers (SPEC-055 §4 allows either), since `creatureLabel(token)` has no `players` argument

not change (`packages/shared` types/schemas/migrations/store/contract, `VectorMapView`,
`TokenPickerDialog`, `vttcamp.test.ts`); left alone under RULE-015 and logged as IN-225.
