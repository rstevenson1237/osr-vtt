# WI-194 — `CampaignStore` split by domain

SPEC-057 §5, DEC-117. Single unit (Shape A). IN-174. Model `sonnet`, effort high.

## Changes made

- `packages/shared/src/store/campaign-store.ts` — the ~925-line `CampaignStore` body is
  cut into `RoomStore` (auth/accounts, room doc + settings, My Rooms, seats, profiles, log,
  `.vttcamp` export/import), `MapStore` (maps, backgrounds, hex overlays, tokens, groups,
  symbols, map rooms, vector geometry, drawings), `EncounterStore`, `DiceStore` (rolls,
  shared rolls, macros, tables, blind drawer), `CollabStore` (handouts, asset refs, Yjs) and
  `PresenceStore` (cursors, drags, pings, presence). `CampaignStore extends` all six with an
  empty body. Every method, signature and doc comment moved verbatim; no implementation or
  caller changed.
- `packages/shared/src/store/contract/` (new) — `room`, `map`, `encounter`, `dice`,
  `collab`, `presence` `.contract.ts` files hold the former `describe` blocks unchanged;
  `helpers.ts` holds the shared helpers (`waitFor`, `pinArrayListener`, …) and
  `ContractContext`.
- `packages/shared/src/store/campaign-store.contract.ts` — now a 90-line runner: it creates
  the two clients and calls each domain's `define…Contract`, so `MemoryStore`,
  `FirebaseStore` and `LocalStore` still run everything from the same entry point.
- Docs: `README.md` (test-culture section), `PLAN.md`, `PLAN-COMPLETED.md`, `INTAKE.md`.

None.
