draw no snap dot (unchanged). No other tool's behavior changes.

vector map, select the Symbol tool with Cell or Half snap active, and move the pointer
over the canvas — a faint highlighted cell (half-cell under Half) should track the
pointer and disappear under Free snap; repeat for the Label tool. `snap-cell-readout`
reflects the same cell for both tools, matching Room's existing readout format.
