## WI-079 — Free snap attracts to an existing vertex (Wall/Door/Polygon + the lasso's vertex handles; not the cell-anchored tools)

**Changes made.**

- `packages/shared/src/map/vector/snap.ts` — new `VertexAttraction` interface
  (`vertices`, `radius`, both in lattice units) and `nearestVertexWithin(p,
  vertices, radius)`, which returns the nearest candidate strictly inside the
  radius as a **fresh point** (never a reference into the caller's live
  geometry) or `null`. `snapPoint` gains an optional third parameter: in
  `free` mode it returns that vertex when one is in range and the raw point
  otherwise, so every existing two-argument caller keeps the identity it always
  had. The snapped modes ignore the parameter — they already round to lattice
  vertices. The file's header doc no longer claims Free is unconditionally
  identity.
- `apps/web/src/lib/map/vector-tools.ts` — `VERTEX_ATTRACT_TOOLS` /
  `attractsToVertex(tool)`: Wall, Door, Polygon. Documented against
  `CELL_ANCHORED_TOOLS` directly above it as the explicit exclusion (SPEC-028
  §2's standing constraint), and records why Select is not in the list — its
  gate is drag state, not the tool.
- `apps/web/src/lib/components/VectorMapView.svelte` — new
  `vertexAttraction()` between `toLatticeRaw` and `toLatticeSnapped`, and
  `toLatticeSnapped` now passes its result to `snapPoint`. Three gates: the
  effective snap mode must be `free` (so Alt-held freeform gets it too);
  the tool must pass `attractsToVertex`, except under Select where the gate is
  `activeDrag !== null` — a vertex-handle drag in progress; the candidates are
  `vertexHandles(regions, walls, doors)` at `latticeThreshold(PICK_PX)`, the
  same catalog and the same radius the Select tool picks with.
- `packages/shared/src/map/vector/snap.test.ts` — a `snapPoint` vertex-attraction
  block (attracts inside the radius, identity outside it, identity with no
  attraction passed, nearest-of-two, returns a copy, snapped modes unaffected)
  and a `nearestVertexWithin` block (empty list, zero radius, exclusive at the
  boundary).
- `apps/web/src/lib/map/vector-tools.test.ts` — `attractsToVertex` covers the
  three tools, excludes every entry of `CELL_ANCHORED_TOOLS`, and excludes
  `select`.
- `docs/spec/SPEC-028.md` — status **Active → Completed**; the third reopening's
  header line records that WI-079 landed §12.
- `SPEC.md` — the SPEC-028 index row follows the body to `Completed`.
- `README.md` — a "Free snap attracts to an existing vertex" paragraph after
  "Cells, not intersections": what the radius is, which catalog the candidates
  come from, which tools and gestures are in and out.
- `PLAN.md`, `PLAN-COMPLETED.md`, `INTAKE.md` — ledger moves (WI-079 out of §2,
  into §3; IN-050 from §1.1 to §1.2).

**Visible behavior changes.**

Under **Free** snap only (the Snap selector set to Free, or Alt held): drawing a
Wall, Door or Polygon point within the pick radius — 9 screen px on a fine
pointer, 22 on a coarse one, so the lattice-space tolerance shrinks as you zoom
in — of an existing floor-ring corner, wall endpoint or door endpoint places the
point on that vertex exactly instead of a fraction of a unit off it. The same
applies to a Select vertex-handle drag, which now lands flush on a vertex it is
released near. The live snap dot shows the attracted position while drawing, so
the pull is visible before the click commits. Cell and Half snap are unchanged;
so are Room, Corridor, Path, N-gon and Carve in every mode, Select's initial
pick, and Select's whole-object drags (labels, symbols, pen drawings).

**How to verify.**

- `pnpm verify:all` — the two new unit blocks are in `packages/shared`'s
  `snap.test.ts` and `apps/web`'s `vector-tools.test.ts`. (`pnpm verify` alone
  cannot pass in a bare checkout: `test:unit` includes
  `packages/shared/src/store/account-recovery.emulator.test.ts`, which needs the
  auth emulator — see Deviations.)
- By hand: open a map with existing geometry, set Snap to **Free**, pick **Wall**,
  and click just off an existing wall endpoint — the new segment starts exactly
  on it. Repeat with **Door** and **Polygon**. Then take **Select**, drag a
  vertex handle near another vertex and release: it lands on it. Switch to
  **Carve** or **Room** under Free and confirm nothing is attracted.
