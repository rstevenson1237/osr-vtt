## WI-129 — Road and River lose the shade selector; the shade is the width

**Status: Completed 2026-09-14**

The toolbar offers width only for the hex Road/River tools. The shade index a line
commits is now derived from the width index it was drawn with — thin is the kind's
lightest shade, thick its darkest — instead of being picked independently from a second
control.

### Changes made

- **`apps/web/src/lib/shell/map-tool-controller.svelte.ts`** — removed the
  `selectedHexLineShade` state field; its doc comment on `selectedHexLineWidth` now notes
  the width also indexes the shade (SPEC-047 §14).
- **`apps/web/src/lib/components/shell/MapToolPalette.svelte`** — dropped the
  `bind:selectedHexLineShade` wire to `MapToolbar`.
- **`apps/web/src/lib/components/MapToolbar.svelte`** — removed the `selectedHexLineShade`
  prop/type, the `activeHexLineShades` derived value, and the `Shade:` swatch-row markup
  (`data-testid="hex-line-shade"`/`hex-line-shade-{i}`) together with its now-unused
  `.swatch-row`/`.swatch` CSS. The Road/River param group is Width only.
- **`apps/web/src/lib/components/VectorMapView.svelte`** — both `store.addHexLine`'s
  committed write and `hexLinePreview()`'s ghost now derive `shade` from
  `mapCtrl.selectedHexLineWidth` instead of reading a separate `selectedHexLineShade`.
- **`README.md`** — the hex-overlay section's preview note ("the referee is choosing among
  three widths and three shades") corrected to reflect that only the width is chosen; the
  shade follows (SPEC-047 §14).
- **`docs/spec/SPEC-047.md`** §14 already documented this behaviour (written at the gate);
  no spec text change was needed.

### Visible behavior changes

The Road/River toolbar panel no longer shows a row of shade swatches — only the Width
select remains. Drawing a line now derives its colour tone from the chosen width (thin =
lightest, thick = darkest) rather than from an independent shade pick. Lines already
drawn are unaffected: `HexLine.shade` is unchanged in meaning and stored value, so
existing roads/rivers render exactly as before.

### How to verify

1. `pnpm verify` — lint, typecheck, unit all green.
2. On a hex map, select Road or River: the parameter row shows only a Width select, no
   shade swatches.
3. Draw a thin line, then a thick line of the same kind: the thin one renders in the
   kind's lightest shade, the thick one in its darkest — both the live preview and the
   committed line.

### Deviations

None — the change matched the approved gate exactly.
