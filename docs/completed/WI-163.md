**Changes made**

- `apps/web/src/lib/components/MapToolbar.svelte` — on a hex map, two visible row
  headings are added: **Inspect** above the Select row, and **Paint** above the
  hex-only overlay row (Label/Symbol/Road/River/Terrain). Each heading carries a
  tooltip stating that both rows write the same terrain-and-notes fields (Paint by
  clicking; Inspect by opening `HexTilePanel` on the selection). A `.row-heading` style
  (small, dim, uppercase — matching the existing group-label idiom) is added. No tool,
  id, or `data-testid` changes; square-grid maps are unaffected (`isHexMap` gate).
- `README.md` — a bullet under the hex-tools discussion (§"Tools") documents the two row
  headings.

**Visible behavior changes** — on a hex map only, the tool palette shows "Inspect" above
the Select tool and "Paint" above the hex overlay tools row.

**How to verify** — `pnpm verify` green (lint, typecheck, unit). Manually: open a hex map,
confirm the palette shows "Inspect" over Select and "Paint" over the Label/Symbol/
Road/River/Terrain row; open a square-grid map, confirm neither heading appears.
