## Deviations

- **More handed than SPEC-068 §4 listed.** `renderableTokens`, `mapVisibleIds` and `revealedAt`
  are getters (the dimming and a late image failure need them and they stay in the component,
  §1); the engine is the structural type `TokenLayerEngine`, which adds
  `app.renderer.generateTexture` for the placeholder; `loadArt?` lets a unit test replace the
  DOM-bound `loadTokenArt`. SPEC-068 §4 now says so. Unblock exception.
- `aimEye(pos)` is handed the token's pixel position and the component divides by `cellSize`, so
  the controller gains no conversion. SPEC-068 §4 reworded.
- The mirror is `tokenLetterText`, not `tokenLetterText_`; `addingCreature` is a plain private
  field, not `$state` (nothing reads it reactively). `destroy()` clears the five lookups the
  component's `onDestroy` cleared before (SPEC-068 §5 reworded; it said "six").
- `tokenAt` (dead) and the unused imports `tokenRadiusPx`, `objectBounds`, `pickMapRoomAt`,
  `pickNoteDotAt`, `sameHandle`, `hexMeasureSpanText` were already unused and are not code this
  item moved, so they stay. Logged as IN-234.
- No RULE-015 Deviations-budget fix was made.
