# WI-235 — Remove the first-start hints

**Closed 2026-11-18.** From IN-236; DEC-138 supersedes SPEC-054 §1 (empty-map card, "Show me around") and §3 (first-visit labels). Model target `sonnet`, run on `sonnet`; effort `high`.

---

## Changes made

- `apps/web/src/lib/shell/shell-state.svelte.ts`: removed `HintId`, `closedHints`, `dismissedHints`, `railSeen`, `dismissHint`, `markRailSeen` and `resetHints`, and their load/persist handling. Old stored `dismissedHints`/`railSeen` values are ignored on load and not written back.
- `apps/web/src/lib/components/RoomShell.svelte`: removed the empty-map hint card and its CSS, the `showLabels` props, the `markRailSeen()` calls and the `onShowMeAround` wiring.
- `apps/web/src/lib/components/shell/QuickSheetRail.svelte`, `MainViewTabs.svelte`: removed the `showLabels` prop and the `labeled` styling. The mobile chips keep their visible titles.
- `apps/web/src/lib/components/shell/ShortcutSheet.svelte`: removed the "Show me around" button, its style and the `onShowMeAround` prop.
- `apps/web/src/lib/components/VectorMapView.svelte`, `apps/web/src/lib/shell/map-tool-controller.svelte.ts`: removed the `mapIsEmpty` mirror, which only the empty-map card read.
- `apps/web/src/lib/shell/shell-state.svelte.test.ts`: replaced the first-run-cue tests with one asserting that legacy stored values are ignored on load and dropped on the next write.
- `docs/spec/SPEC-054.md` (§1, §3 annotated superseded in place), `README.md` (rail, State, First-run cues), `PLAN.md`, `PLAN-COMPLETED.md`, `INTAKE.md`: docs and bookkeeping.

## Visible behavior changes

- Rail icons no longer show text labels on a viewer's first visit; they show their `title` tooltips like they do afterwards.
- A referee on an empty map no longer sees the "Draw with Map tools · Add a background in Assets · Invite players" card.
- The `?` shortcut sheet no longer has a "Show me around" button.
- The empty Encounter board hint, the View-lock tool hint and every other cue are unchanged. No stored data migrates; old browser values are just ignored.

## How to verify

- `pnpm verify`; open a new room as referee: rail shows icons only, no card over the empty map; open `?`: no "Show me around".
- In devtools, `localStorage['vtt-shell:<roomId>']` gains no `dismissedHints` or `railSeen`.

## Deviations

- None. No Playwright spec referenced `empty-map-hint`, `empty-map-hint-dismiss` or `show-me-around` (grep), so no spec changed.
