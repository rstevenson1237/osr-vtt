# WI-155 — "Switch to Edit to draw" hint

SPEC-054 §4. Part of Batch 1 (WI-152–158) — one pull request, one combined summary.

**Changes made**

- `MapToolbar.svelte` — a locked drawing tool button switches from `disabled` to
  `aria-disabled` (so it can still receive a click) with a `.locked` visual class; its
  click handler shows a one-line hint ("Switch to Edit to draw") beside
  `map-mode-toggle` for 3s instead of switching the tool. Applies to both the main tool
  grid and the hex-only tool row.

**Visible behavior changes** — clicking a disabled draw tool under the View lock now
shows a transient hint instead of doing nothing. The lock, its `'view'` default and
`isViewTool` are unchanged; no tool becomes reachable under the lock that wasn't before.

**How to verify** — `pnpm verify:all` green. Manually: switch a map to View mode, click
a disabled drawing tool (e.g. Wall), confirm the hint appears beside the Edit/View
toggle and fades after a few seconds.

**Deviations** — none.
