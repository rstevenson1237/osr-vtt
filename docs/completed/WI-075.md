## WI-075 — Snap-mode selector on the Label and Symbol tools

**Status: Completed 2026-08-11**

### Changes made

**`apps/web/src/lib/components/MapToolbar.svelte`** (line 250): Added `'label'` and `'symbol'` to the `SNAP_TOOLS` array, which determines which tools display the snap mode selector in the tool parameters section.

This single-line change surfaces the snap mode control for Label and Symbol tools, which already honour the active snap mode (implemented in WI-068) but had no UI to select it.

### Visible behavior changes

- When the **Label** tool is active, the snap mode selector appears in the tool parameters section alongside the other snap-mode-aware tools (Room, Corridor, Path, Polygon, N-gon, Carve, Wall, Door).
- When the **Symbol** tool is active, the snap mode selector appears.
- Users can now change the snap mode while these tools are active, and the mode change applies to Label and Symbol placement (cell-snapped, half-cell-snapped, or free).

### How to verify

1. Open a map in edit mode.
2. Select the **Label** tool.
3. Verify that the "Snap:" selector appears in the tool parameters section below the tool grid.
4. Verify it shows the current snap mode (defaults to "Cell").
5. Change the snap mode in the selector and verify it updates the controller's `snapMode`.
6. Select the **Symbol** tool.
7. Repeat steps 3–5 for Symbol.
8. Verify that placing a label or symbol respects the selected snap mode: cell anchors to the cell centre, half anchors to the half-cell centre, free uses raw coordinates within snap radius of existing vertices.

### Deviations

None. Implementation exactly matched the gate's specification: "Both tools already honour the mode (WI-068); this surfaces the control."
