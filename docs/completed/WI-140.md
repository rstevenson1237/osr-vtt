# WI-140 — The panel swap

**Spec:** SPEC-051 §§1, 3 · **From:** IN-134 · **Agent:** `claude-code` · **Model:** `sonnet`
· **Effort:** L · **Closed:** 2026-09-19

## Changes made

Every typed Unicode character IN-134's audit found (`docs/mockups/icon-audit-2026-09-18.html`)
is replaced with an `<Icon>` call against the 41 ids WI-139 added, across 20 components (the
17 SPEC-051 §5's audit named, plus `EncounterBoard` and its own 🎲 shortcut, `RollSheet`'s
staged-die ✕, and `SessionActivity`'s band-remove ×, all three carried by the same "close"/
"dice" TYPED rows the audit already listed):

- `QuickSheetCard`, `Dialog`, `ShellOverlay`, `MapsPanel`, `BackgroundsPanel`,
  `AssetsActivity`, `HandoutPanel`, `MacroList`, `RollSheet`, `SessionActivity` — `✕`/`×` →
  `close`.
- `RoomsPanel` — undo/redo/check/close/expand/pencil(existing)/grip; the legend line stays
  typed text (content describing the row, not a control).
- `CombatTracker` — `▶`/`◀` → `chevron-right`/`chevron-left` (Rotate, both Round buttons,
  Previous, Next); `🎲` → `dice`; `×` → `close`.
- `TensionBar` — `▲`/`▼` → `chevron-up`/`chevron-down`, each gaining an `aria-label`
  (`Increase`/`Decrease {field.label}`) since it had none.
- `CharacterSheet` — `←` → `arrow-left`.
- `ProfileTemplateEditor` — `📌`/`↑`/`↓`/`✕` → `pin`/`arrow-up`/`arrow-down`/`close`, the
  three that had no accessible name gaining `aria-label` (Move up/down, Remove field).
- `MobileTopBar` — `⏺` → `person`.
- `SessionTab` — the referee badge moves off a CSS `::after` `content: '♦'` onto a real
  `<Icon name="crown" size={10}>` in a new `.ref-badge` span (a stylesheet can't reference
  `Icon.svelte`'s markup); the badge's fixed 10px size is not device-scaled, unlike every
  other swap in this item.
- `RoomShell` — the rail-move handle's `⟨`/`⟩` → `panel-left`/`panel-right`.
- `MarkdownEditor` — `•`/`¶` → `list`/`paragraph` (both already had `aria-label`).
- `CharacterDock` — counter `−`/`+` → `minus`/`plus` (gaining `aria-label`s), roll-chip `🎲`
  → `dice`.
- `MapToolbar` — "+ Add creature" → `add-person` beside the kept label, per SPEC-051 §7 (a
  labelled button that gains a glyph keeps its label).
- `EncounterBoard` — the per-token roll-shortcut `🎲` → `dice`.
- `README.md` "Icon system" section — new paragraph stating SPEC-051 §1's rule and its two
  exclusions, and that the 41 ids now back real controls.

## Visible behavior changes

Roughly forty controls across the panels, sheets, dice tray, combat tracker and map toolbar
now render a drawn 1.75-stroke glyph instead of a platform-rendered Unicode character —
same silhouette family, no colour, no per-OS variance, no emoji. A handful of controls that
previously had no accessible name (`TensionBar`'s two step buttons, `ProfileTemplateEditor`'s
move/remove buttons, `CharacterDock`'s two counter buttons, and the delete buttons in
`AssetsActivity`, `HandoutPanel`, `MacroList` and `SessionActivity`'s band row) now announce
one. The referee's presence-chip badge is drawn slightly differently (a crown outline
in place of a solid diamond) but occupies the same position.

## How to verify

`pnpm verify` — lint, typecheck and unit all green. Visually: open a room as GM, check the
Rooms/Maps/Backgrounds/Assets/Handouts panels, the dice tray's macro list and staged Roll
sheet, the Combat tracker (Free and structured modes), Tension bar, a Profile template
editor, the mobile top bar's presence count, the Session tab's referee badge, the rail-move
handle, a Markdown editor's list/paragraph buttons, a character's counter field, and the map
toolbar's "Add creature" button — none types a Unicode character.

## Deviations

None — `EncounterBoard`, `RollSheet` and `SessionActivity` were folded in because
SPEC-051 §5's own TYPED audit table (not just the 17-component prose list) named their
glyphs (`🎲` "CombatTracker, CharacterDock, **EncounterBoard**"; `close` row's "…MacroList,
**RollSheet**…, **SessionActivity**, CombatTracker"), so leaving them out would have been a
partial delivery of the same audit finding, not a narrower one.
