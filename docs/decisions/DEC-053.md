## DEC-053 — What "the drag has declared an axis" means, which DEC-048 leaves open

- **Question.** DEC-048 and SPEC-028 §11 pin the latch to a threshold but describe it two
  ways in one sentence: the drag must have "moved further than a latch threshold along one
  axis **than the other**". Read literally that is a _difference_ test —
  `|dx| − |dy| > t` — and a drag held near the diagonal then satisfies it at no distance
  at all, so a corridor dragged five cells south-east would stay a single straight leg
  indefinitely. Read as a _magnitude_ test — `max(|dx|, |dy|) > t`, latching whichever is
  larger — a diagonal drag latches almost immediately on whichever axis happens to lead by
  a hair.
- **Recommendation.** **The magnitude test, with a tie held open**: latch the first time
  the longer axis passes the threshold, take that axis, and latch nothing while the two
  deltas are exactly equal. It keeps §11's own justification intact — "before the
  threshold is met there is no bend to place" is true precisely because, under snap, both
  endpoints are still in the same cell and `corridorPoly` emits one leg anyway — while
  never leaving a large drag unlatched.
- **Impact.** The two readings agree on every gesture the item was actually about (an
  L-shaped drag, which leads decisively on one axis before it turns). They differ only for
  a drag held close to the diagonal, where the magnitude test commits early on a slim
  lead. That is the visible cost: near-diagonal drags will pick an axis the referee did
  not consciously choose. It is the lesser cost, because the alternative is a _large_
  gesture with no bend at all, which reads as the tool being broken rather than as it
  guessing. The threshold `BEND_LATCH_LATTICE = 0.5` (half a cell) is the second agent
  default here — the smallest travel that can change which cell the pointer is in under
  Cell snap, and therefore the smallest that can produce a bend. Both are reversible in
  one small pure function, `latchBendAxis`, which is unit-tested directly and takes the
  threshold as a parameter.
- **Alternatives.** (a) The literal difference test — faithful to the sentence, and it
  leaves a long diagonal drag as one straight leg, which no reading of the request wants.
  (b) A difference test _plus_ a fallback that latches on magnitude once the drag is long
  enough — correct in both regimes, but it is two thresholds and two rules to explain for
  a case that ends the same way. (c) Latch on the first `pointermove` with any lead at all
  — no threshold, and a one-pixel twitch then decides the shape of the corridor.
- **Answer.** Agent default (Default-and-notify), surfaced in WI-062's completion summary.
