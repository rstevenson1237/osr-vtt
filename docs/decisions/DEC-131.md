## DEC-131 — IN-206: what happens to the grid testids when grid and fog move to Assets?

**Closed 2026-10-07** — agent default under `/work-item` (IN-206), surfaced at the WI-222
gate.

- **Question.** IN-206 moves Grid & measurement and Fog of war out of Session settings into
  a Map settings panel in Assets (SPEC-064). Five testids carry the old surface's name:
  `session-grid-w/h/cellsize/apply/error`. Rename them, or move them as they are?
- **Default.** **(a) Rename to `grid-*`** (`grid-w`, `grid-h`, `grid-cellsize`,
  `grid-apply`, `grid-error`), matching the unprefixed ids already beside them
  (`grid-subdivide-toggle`, `measure-*`, `fog-enabled-toggle`). This follows the
  backgrounds move (SPEC-038 §5), which retired `session-background-*` for `background-*`.
- **Impact.** Three e2e files change in the same PR (RULE-005): `session-config.spec.ts`,
  `backgrounds.spec.ts`, `helpers.ts`. They change anyway, because each must open Assets
  instead of Session settings. No stored data, store, rules or schema change.
- **Alternatives.** **(b) Keep the `session-` ids**, as the handouts move did (SPEC-056 §1):
  a smaller diff, but the ids then name a surface the controls no longer sit on.
