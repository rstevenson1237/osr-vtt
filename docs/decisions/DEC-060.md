## DEC-060 — One Select tool, lasso included; `selectEdge` is retired

- **Question.** IN-049 asks for a lasso that selects vertices and objects together, with
  Backspace removing the selection. Select is currently three tools —
  `selectVertex` / `selectEdge` / `selectObject` (WI-030) — each a single-pick gesture.
  Does the lasso become a fourth tool alongside the three, or does it replace them?
- **Recommendation.** Replace all three with one Select tool: click still single-picks (a
  vertex, or an object — vertex takes priority under the pointer, matching today's
  vertex-mode precedence), and a drag lassoes a region, collecting every vertex handle and
  object inside it into one multi-selection. `selectEdge` is retired outright, not folded
  into the merge — an edge is not a first-class handle in the merged model, only its two
  vertices are.
- **Impact.** `MapToolId` loses `selectVertex` / `selectEdge` / `selectObject` and gains one
  `select`; `selectModeForTool` and `ToolPreviewInput.selectMode` collapse accordingly, and
  `tool-groups.ts`'s `select` group goes from three tools to one. **A real capability is
  lost**: `edgeHandles` (`vector-tools.ts`) is what lets a referee grab a wall, a door, or a
  floor-ring edge and drag both endpoints as one gesture. After this change, moving a wall
  means dragging each endpoint separately. `deleteSelectedObject` extends to a multi-target
  delete over the new selection set; vertex deletion additionally has to preserve the ring
  it came from where possible (SPEC-037). Every Select-tool Playwright assertion
  (`map-draw-feedback.spec.ts` and any that pick `vector-tool-select-*`) is rewritten in the
  same PR (RULE-005).
- **Alternatives.** (a) A fourth `selectLasso` tool alongside the existing three — no
  capability loss, smaller diff, but leaves four tools doing overlapping work and the
  request asked for lasso selection of "vertices and object selection" as one gesture, which
  reads as a merge, not an addition. (b) Keep `selectEdge` and let the lasso pick edges too
  — preserves edge-dragging, but complicates what a "vertex the lasso caught" means when an
  edge and its two endpoints are all inside the region.
- **Answer.** User, 2026-08-11 — replace all three with one Select tool with click + lasso;
  drop the edge selector. Accepted with the capability loss above explicitly noted.
