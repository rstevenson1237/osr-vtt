## DEC-109 — Select joins the View tools: tokens are selectable and movable, geometry read-only

**Closed 2026-09-23** — answered by the user under `/work-item` (IN-167).

- **Question.** The lasso collects vertices and objects, never tokens, and Select is disabled
  under the View lock while token dragging is not. How are several tokens selected, and what
  does Select do under View?
- **Answer.** (user, 2026-09-23)
  - **Select (with its lasso) moves into the View group**, so it is live under the View lock.
  - **Under View it selects tokens, and geometry read-only**: vertices, symbols, labels, doors
    and drawings can be selected to inspect (tooltip, note) but not moved or deleted.
    **Under Edit** it grabs everything, as today.
  - **Shift-click** adds or removes a token in either mode.
  - **A lasso that catches any token selects tokens only.** Backspace never deletes a token.
  - Dragging any selected token moves the set: RTDB drag frames while dragging, one
    `moveTokens` batch on release (RULE-003).
- **Impact.** Changes SPEC-037's selection model and README's Edit/View lock paragraph
  (`isViewTool` gains `select`, with a mode-dependent grab set). The View lock still prevents
  every geometry write.
- **Alternatives.** Keeping Select Edit-only (lasso in Edit, Shift-click everywhere) and a
  fully live Select under View were offered; the second would have emptied the lock.
