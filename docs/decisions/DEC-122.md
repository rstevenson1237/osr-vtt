## DEC-122 — Which name does an unnamed creature show?

**Closed 2026-10-02** — answered by the user under `/work-item` (IN-218).

- **Question.** WI-169 found two name rules for a seatless creature with no name.
  `tokenLabel`/`refLabel` show the stored `letter` if set, else `<art basename> · <id6>`;
  `creatureLabel`/`creatureDisplayName` ignore `letter` and show the bare basename (or
  `Token <id6>`). SPEC-055 §4 kept both. Which wins everywhere?
- **Recommendation.** The `tokenLabel` rule: letter, then `basename · id6`. Two creatures
  sharing art stay distinguishable, and it is already what `actorPresentation` computes.
- **Impact.** Visible copy change on the Character sheet's creature header and the
  Encounter board's card name for unnamed creatures only; no schema, store or testid change.
  Amends SPEC-055 §4's "keep today's per-surface answer" for this one case.
- **Alternatives.** (b) Letter, then bare basename — cleaner, but same-art duplicates read
  the same. (c) Keep both — leaves the inconsistency SPEC-055 §4 set out to remove.
- **Answer.** **The recommendation — letter, then `basename · id6`** (user, 2026-10-02).
  Scheduled as WI-214.
