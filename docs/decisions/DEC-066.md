## DEC-066 — The battle-map quick sheet's button arms the existing canvas gesture; `capture` leaves `TOOL_GROUPS`

- **Question.** IN-059 asks to move the capture tool from the map-tools quick sheet to the
  battle-map quick sheet. Capture is a canvas gesture today — click-and-drag (or click,
  click) over the map, in the `shapes` group of `TOOL_GROUPS`, referee-gated inside
  `MapToolbar` rather than in the catalog itself. What does "move it to the other sheet"
  mean for a gesture that has to happen on the canvas?
- **Recommendation.** The battle-map quick sheet gains a "Capture area" button; clicking it
  sets `MapToolController.activeTool = 'capture'` exactly as picking it from the palette
  does today, and the drag still happens on the map canvas — SPEC-029 §1's gesture is
  unchanged, only its entry point moves. `capture` is removed from `TOOL_GROUPS`'s `shapes`
  group entirely (not merely hidden), since the map-tools palette should no longer offer it
  at all.
- **Impact.** `tool-groups.test.ts`'s "every `MapToolId` belongs to exactly one group"
  invariant needs an explicit, named exemption for `capture` — it becomes the one `MapToolId`
  reachable only from outside `TOOL_GROUPS`. `MapToolbar.svelte`'s referee-only capture entry
  (`(id) => (id !== 'capture' || isGM) && ...`) is deleted along with the rest of that
  filtering, since the tool no longer appears in the palette at all. `vector-tool-capture`'s
  testid moves to the battle-map quick sheet; `battle-map-capture.spec.ts` and
  `battle-map-lifecycle.spec.ts` (four assertions total) are updated in the same PR
  (RULE-005). SPEC-029 §1 is amended in place to describe the sheet-button entry point.
- **Alternatives.** (a) Sheet-only with no palette entry, keeping `capture` in `TOOL_GROUPS`
  but never rendering it in the map-tools palette — rejected as unnecessary complexity; if it
  is leaving the palette, it should leave the catalog too, cleanly. (b) Duplicate entry
  points, in both the palette and the sheet — declined: two ways to reach one tool
  contradicts the point of moving it.
- **Answer.** User, 2026-08-11 — the sheet button arms the canvas tool, as recommended.
