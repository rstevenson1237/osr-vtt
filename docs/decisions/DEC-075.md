## DEC-075 — A local build ships as a static bundle plus a launcher script, with no new runtime dependency

**Closed 2026-08-17** — answered by the user at this batch's gate (option (a) of three).

- **Question.** IN-066 asks how a local build is packaged and distributed to someone who
  wants to run it themselves, with no tie-in to this project's Firebase project.
- **Answer.** A **self-contained static bundle** built with no Firebase configuration, plus
  a one-command launcher that serves it locally and a short README, released as a zip. No
  Electron, no Tauri, no installer, no new runtime dependency.
- **Why not a desktop app.** Tauri or Electron would give real native file dialogs and a
  double-clickable icon — genuinely nicer for "open my campaign file" — at the cost of a
  Rust or Chromium toolchain, per-platform release builds, and a signing story, all of which
  become permanent maintenance on a project whose whole premise is that it has no backend to
  maintain. That trade can be revisited as a fresh intake item once local mode has actually
  been played with.
- **Why not "just serve the directory yourself".** The app needs an HTTP origin — the File
  System Access API and ES modules both refuse `file://` — so "run locally" without a
  launcher still means "know how to serve a directory", which is the exact audience the
  request is trying to include.
- **Impact.** A `build:local` script and a Vite mode that strips the Firebase configuration,
  a launcher, a distribution README, and a release artefact. The hosted build's pipeline is
  untouched. **The load-bearing assertion is that the local bundle contains no Firebase
  code and no project identifiers** — that is what "no tie-ins to our existing firebase
  project" means, and it is checkable in CI rather than by inspection.
- **Overridable**: WI-090 is an investigation and may find that the launcher needs to be
  something other than a node script (a Python one-liner, a prebuilt static-server binary);
  the shape — bundle plus launcher, no app framework — is what is decided here.
