OSR VTT icon audit

docs/mockups · 2026-09-18 · against commit 2261bda · Icon.svelte, 39 glyphs · shell + map palette + panel chrome

What this page is: a read of every icon-shaped control in the hosted and local shells, on a mouse and on a phone, followed by a redraw. Every "old" glyph below is rendered straight from the MARKUP record in Icon.svelte; every "new" one obeys the same technique rule (24-unit grid, 1.75 stroke, round caps, currentColor, no wrapper), so each is a drop-in replacement for one record entry, not a new icon system. The subject rule in SPEC-043 §2 is kept: implement first, then the thing, then the resulting shape.

Findings, by impact

    The consistency rules the redraw follows

    SPEC-043 already fixes technique and subject. The set drifts in ways those two rules do not reach, so the redraw adds five more, all of which a reviewer can check by eye:

    • One ink weight. Every glyph carries between roughly 30 and 55 units of stroke length. Nothing is a lone hairline (the old encounter) and nothing is a solid slab. Filled details are dots of radius 1.3–1.8 only.
    • Sixteen-pixel floor. Every glyph is drawn to survive 16px: no counter narrower than 3 units, no two parallel strokes closer than 2.5 units. Chrome renders at exactly three stops, 16 / 20 / 24, never 14 or 15.
    • No typed characters as icons. A verb in the chrome (close, expand, undo, reorder, lock) is a glyph from the record, never ✕, ⤢ or an emoji. Bold and italic keep their letters: that is typographic convention, not an icon.
    • Mirror pairs share geometry. Undo/redo, expand/collapse, lock/unlock, chevrons, panel-left/right, upload/download are one drawing flipped, so the pair reads as a pair.
    • One id per meaning. A glyph is reused only where the meaning is the same (Rename uses pencil; the roll shortcut uses dice). Two tools with different meanings never share a glyph, which is what Road, River and Terrain currently do.

    What this is not

    Not a change of the button anatomy, the group colours, the hit sizes or any data-testid: every control keeps its testid and its accessible name, and a glyph swap inside an aria-hidden SVG is invisible to the Playwright suite. Not a redraw of catalogue art (map symbols, door variants, hex terrain), which SPEC-043 §5 places out of scope. And not a scheduled change: under RULE-015 this page is the input to an intake item, and the split it implies is one work item for Icon.svelte (record entries, the IconId union, the three size stops) and a second for replacing the typed characters in the seventeen components, which touches more files but changes no contract.
